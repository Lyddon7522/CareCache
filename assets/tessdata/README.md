# Tesseract English model

`eng.traineddata` is the English `tessdata_fast` model from the official Tesseract project. It is
bundled so label recognition works without a network connection. Keep the source revision and
SHA-256 below in sync whenever the model changes.

- Source: `https://github.com/tesseract-ocr/tessdata_fast`
